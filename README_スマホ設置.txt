ジムノート PWA v3（スマホ設置用）

このZIPはスマホからGitHubへアップロードしやすいよう、必要ファイルを全部1階層に置いてあります。

GitHubにアップロードするファイル:
- index.html
- styles.css
- app.js
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

README_スマホ設置.txt はアップロードしなくても構いません。

重要:
gym_note_private_setup.json はGitHubへアップロードしないでください。
これは個人の身体データ・目標を端末へ読み込むための非公開ファイルです。

設置後:
1. GitHub PagesのURLをChromeで開く
2. 設定 → バックアップ / 初期設定を読み込む
3. gym_note_private_setup.json を選択
4. Chromeの「アプリをインストール」または「ホーム画面に追加」
